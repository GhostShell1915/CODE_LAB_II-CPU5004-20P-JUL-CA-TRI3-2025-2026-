 Weather_APP - Code Lab II Assessment 2

A custom Weather Application developed using the openFrameworks creative coding toolkit inside Visual Studio 2022.

 Requirements & Setup For Evaluators

To keep the repository light and comply with GitHub's file limitations, the temporary local build caches, compiler outputs, and pre-compiled binaries (`.vs/`, `Debug/`, `Release/`, `*.lib`, `*.exe`) have been safely excluded using `.gitignore`. They will automatically regenerate upon compiling on your machine.

How to Run and Evaluate the Project:

1. Setup Environment: Ensure you have your standard academic installation of openFrameworks extracted on your machine.
2. Download this Source Code: Download this repository as a ZIP archive from the green "Code" button or clone it via your terminal:
   ```bash
   git clone https://github.com
   ```
3. Directory Placement: Move the extracted `Weather_APP` directory into the standard openFrameworks tree structure:
   `openFrameworks/apps/myApps/Weather_APP`
4. Compile the Solution: Open the `Weather_APP.sln` solution file inside Visual Studio 2022.
5. Launch: Set the solution configuration to `Debug` or `Release` under `x64` and click Local Windows Debugger. Visual Studio will automatically resolve the core libraries and compile the live application window!

Implemented Features
 - Dynamic real-time weather data parsing.
 - Interactive graphical user interface (GUI) components.
 - Modular C++ object orientation aligned with Code Lab II technical specification criteria.
